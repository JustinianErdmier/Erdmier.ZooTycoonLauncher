**Goal:** Build the INI tab: display every editable `zoo.ini` key in a single tab grouped by `GroupBox`, support in-memory edits with dirty tracking, gate a Save button on
`IsDirty`, and persist via the existing `IIniParserService` + `IVersioningService` only on Save.

**Architecture:** A new `IniSettingsViewModel` exposes 46 `[ObservableProperty]` fields mapped 1:1 to the editable keys in `ZooIniDefaults`, plus three derived projections:
`PlayMenuMusic` (inverted `noMenuMusic`), `ScreenModeIndex` (drop-down view of `Fullscreen`), and `SelectedLanguage` (drop-down view of `Lang`+`SubLang`). Numeric ranges live in a
new `IniRanges` static class consumed by both `ZooIniDefaults` and the XAML `NumericUpDown` controls. Per-key tooltips are sourced from a centralised resource dictionary. The VM
holds a reference to the disk-of-record `ZooIniModel` (the same instance owned by `MainWindowViewModel.Model` so its `RawDocument` is preserved on the round-trip), syncs from it
via
`ApplyModel`, marks `IsDirty=true` on any property change, and on `SaveCommand` performs: undo snapshot → mutate model → write → re-read for verification → reset `IsDirty`.

**Tech Stack:** C# 13, .NET 10, Avalonia 11.3 (Classic theme), CommunityToolkit.Mvvm 8.x source generators, Microsoft.Extensions.DependencyInjection 8.x, System.IO.Abstractions
21.x. No new dependencies.

**Reference:** [`2026-05-08—ini-tab—design.md`](./2026-05-08—ini-tab—design.md) — design rationale and §9 mapping tables.

**Important conventions** (lifted from `2026-04-29—ini-parser-and-startup.md`):

```csharp
/// <summary>
///     ViewModel for the INI Configurations tab. Exposes the editable keys of <see cref="ZooIniModel" /> as observable properties for two-way XAML binding, tracks an
///     <see cref="IsDirty" /> flag set by any edit, and persists changes to disk via <see cref="IIniParserService.WriteAsync" /> only when <see cref="SaveCommand" /> fires.
/// </summary>
public sealed partial class IniSettingsViewModel : ViewModelBase
{
    private readonly IIniParserService _parser;
    private readonly IVersioningService _versioning;

    // Reference to the disk-of-record model. Preserved across edits so the parser's RawDocument is reused on save (comments + ordering survive).
    private ZooIniModel? _model;

    // Path to zoo.ini, supplied by MainWindowViewModel via ApplyModel. Null => save is impossible (game not located).
    private string? _iniPath;

    // Suppresses MarkDirty during ApplyModel so syncing from disk doesn't flip IsDirty to true.
    private bool _suppressDirtyTracking;

    public IniSettingsViewModel(IIniParserService parser, IVersioningService versioning)
    {
        _parser     = parser;
        _versioning = versioning;
    }

    /// <summary>Parameterless ctor used by the XAML designer only.</summary>
    public IniSettingsViewModel()
        : this(NullIniParserService.Instance, NullVersioningService.Instance)
    {
        ApplyModel(new ZooIniModel(), iniPath: null);
    }

    [ ObservableProperty ]
    public partial bool IsDirty { get; set; }

    [ ObservableProperty ]
    public partial string? StatusMessage { get; set; }

    /// <summary>Replaces the working state with values from <paramref name="model" />, resets <see cref="IsDirty" />, and stashes <paramref name="iniPath" /> for the save path.</summary>
    public void ApplyModel(ZooIniModel? model, string? iniPath)
    {
        _model   = model;
        _iniPath = iniPath;

        if (model is null)
        {
            return;
        }

        _suppressDirtyTracking = true;

        try
        {
            SyncFromModel(model);
        }
        finally
        {
            _suppressDirtyTracking = false;
        }

        IsDirty = false;
    }
```

```csharp
[ RelayCommand(CanExecute = nameof(CanSave)) ]
private async Task SaveAsync()
{
    if (_model is null
        || string.IsNullOrEmpty(_iniPath))
    {
        StatusMessage = "Cannot save: zoo.ini path is unknown.";
        return;
    }

    StatusMessage = "Saving…";

    try
    {
        // 1. Mutate the disk-of-record model in place so its RawDocument is reused (preserves comments + key ordering on round-trip).
        ApplyToModel(_model);

        // 2. Snapshot zoo.ini → zoo.ini.undo BEFORE writing (SDD §8.2).
        await _versioning.CreateUndoSnapshotAsync(_iniPath);

        // 3. Atomic write (temp file + rename) — implemented inside IniParserService.WriteAsync per SDD §11.
        await _parser.WriteAsync(_iniPath, _model);

        // 4. Verification re-read so any normalisation the parser applied is reflected back into the UI.
        ZooIniModel reloaded = await _parser.ReadAsync(_iniPath);
        _model = reloaded;

        _suppressDirtyTracking = true;

        try
        {
            SyncFromModel(reloaded);
        }
        finally
        {
            _suppressDirtyTracking = false;
        }

        IsDirty       = false;
        StatusMessage = "Saved.";
    }
    catch (Exception ex)
    {
        // Per SDD §10: surface the error. IsDirty stays true so the user can retry. Status-bar-only for this milestone (design §3.11).
        StatusMessage = $"Save failed: {ex.Message}";
    }
}
```
